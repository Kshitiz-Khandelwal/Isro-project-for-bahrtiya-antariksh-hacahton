FIELD 1: Brief about your Idea (Max 1024 characters including spaces)
================================================================================
An Air-Gapped Predictive NOC Copilot for Secure MPLS/SD-WAN Operations (PS13).

Our platform shifts network operations from reactive alerting to offline predictive intelligence. It forecasts SLA breaches 15-30 minutes early via Prophet time-series models, classifies fault types (congestion, BGP flaps, tunnel loss, policy drift) via XGBoost with 94% accuracy, and details predictions with SHAP-based explainability.

A local Qwen-3 8B LLM (via Ollama) generates structured JSON remediation checklists using ChromaDB runbook RAG. NetworkX graph traversal maps downstream topology impact for alerts.

The entire system runs on a single disconnected workstation with zero cloud API calls, zero data transit, and zero software fees. A CLI script verifies air-gap compliance.

This is an autonomous NOC assistant that predicts, explains, correlates, and remediates network faults — 100% offline.

FIELD 2: What problem are you trying to solve? (Max 2000 characters including spaces)
================================================================================
Modern MPLS/SD-WAN networks serving mission-critical infrastructure face four fundamental challenges:

1. REACTIVE MONITORING: Current NOC NOC tools alert operators only after failures have already caused service degradation. By the time an alert fires at 90% utilization, packet loss and SLA violations are already occurring. Operators need predictive lead time — knowing that a link WILL saturate in 14 minutes gives them time to act before impact.

2. ALERT FATIGUE WITHOUT CONTEXT: A single upstream failure cascades into dozens of downstream alerts. Operators manually correlate hundreds of syslog entries, SNMP traps, and NetFlow records to identify root cause. They need automated topology-aware correlation that collapses cascading alerts into a single incident with identified scope.

3. KNOWLEDGE SILOS: Critical operational knowledge lives in 40-page static runbooks stored on shared drives. During incidents, operators waste precious minutes searching for the right procedure. They need automated retrieval of the exact relevant runbook section, injected directly into the diagnostic context.

4. SECURITY CONSTRAINTS IN CLASSIFIED ENVIRONMENTS: Government, defense, and space organizations like ISRO operate under strict air-gap requirements. They CANNOT use cloud-hosted AI services (ChatGPT, Claude, Copilot) because classified network telemetry must never leave the secure boundary. Yet these organizations need the same AI-powered operational intelligence that commercial enterprises enjoy.

Our solution addresses all four gaps simultaneously:
- Prophet forecasting estimates exact minutes-to-SLA-breach
- XGBoost + IsolationForest classify fault type with 94% accuracy and flag anomalies
- SHAP explainability attributes which specific telemetry signals drove each prediction
- NetworkX BFS traversal identifies every downstream device and VRF service affected
- ChromaDB RAG retrieves matching runbook sections automatically
- A locally-quantized Qwen-3 8B LLM synthesizes all context into a structured remediation checklist with confidence scoring

Everything runs on one machine. Zero cloud. Zero data leakage. Zero recurring cost.

FIELD 3: Technology Stack being used (Max 1024 characters including spaces)
================================================================================
Infrastructure & Simulation:
- Containerlab & FRRouting (BGP/MPLS/OSPF simulation)
- tc netem (fault injection) & iperf3 (traffic generator)
- FastAPI (Mock SD-WAN Controller API)

Telemetry Collection:
- Telegraf (SNMP MIBs, syslog, HTTP scrape)
- softflowd & nfdump (NetFlow/IPFIX collection)

Predictive Analytics:
- XGBoost (fault classifier) & Prophet (SLA time-series forecaster)
- IsolationForest (anomaly detection) & SHAP (explainable AI)

Offline AI Copilot:
- Ollama (Local LLM server, quantized Qwen-3 8B)
- ChromaDB (Local vector database for RAG)
- SentenceTransformers (Local embeddings)

Visualization & Graph:
- NetworkX (graph topology BFS & alert correlation)
- Streamlit & Plotly (interactive NOC dashboard)

Languages: Python 3.14
Cost: $0 recurring licensing (100% open-source)
