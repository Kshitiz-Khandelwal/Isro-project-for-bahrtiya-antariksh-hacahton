FIELD 1: Brief about your Idea (Max 1024 characters including spaces)
================================================================================
An Air-Gapped Predictive NOC Copilot for Secure MPLS/SD-WAN Operations (PS13).

Our platform shifts network operations from reactive alerting to offline predictive intelligence. It forecasts SLA breaches 15-30 minutes early via Prophet time-series models, classifies fault types (congestion, BGP flaps, tunnel loss, policy drift) via XGBoost with 94% accuracy, and details predictions with SHAP-based explainability.

A local Qwen-3 8B LLM (via Ollama) generates structured JSON remediation checklists using ChromaDB runbook RAG. NetworkX graph traversal maps downstream topology impact for alerts.

The entire system runs on a single disconnected workstation with zero cloud API calls, zero data transit, and zero software fees. A CLI script verifies air-gap compliance.

This is an autonomous NOC assistant that predicts, explains, correlates, and remediates network faults — 100% offline.

FIELD 2: What problem are you trying to solve? (Max 2000 characters including spaces)
================================================================================
MPLS/SD-WAN networks serving mission-critical infrastructure face four challenges:

1. REACTIVE MONITORING: NOC tools alert only after failures cause service degradation. Operators need predictive lead time — knowing a link will saturate in 15 minutes allows preemptive action.
2. ALERT FATIGUE: Upstream failures trigger cascading downstream alerts. Operators manually correlate logs to find the root cause. They need topology-aware correlation that groups cascading alerts.
3. KNOWLEDGE SILOS: Operational playbooks are trapped in static runbooks. During incidents, operators waste time searching files. They need auto-retrieved runbook steps injected into the diagnosis context.
4. AIR-GAP CONSTRAINTS: Secure space/defense environments cannot use cloud AI (ChatGPT/Claude) due to data sovereignty. They need fully offline intelligence inside a secure boundary.

Our solution resolves these gaps:
- Prophet forecasts minutes-to-SLA-breach
- XGBoost & IsolationForest classify faults (94% accuracy) and flag anomalies
- SHAP explains which telemetry signals drove the warning
- NetworkX BFS finds downstream devices and VRF services affected
- ChromaDB RAG retrieves matching runbooks
- Local Qwen-3 8B LLM structures diagnostics into a JSON remediation checklist

The system runs on one machine with zero cloud transit and zero licensing costs.

================================================================================
Infrastructure & Simulation:
- Containerlab & FRRouting (BGP/MPLS/OSPF simulation)
- tc netem (fault injection) & iperf3 (traffic generator)

Telemetry Collection:
- Telegraf (SNMP MIBs, syslog, HTTP scrape)
- softflowd & nfdump (NetFlow/IPFIX collection)

Predictive Analytics:
- XGBoost (fault classifier) & Prophet (SLA time-series forecaster)
- IsolationForest (anomaly detection) & SHAP (explainable AI)

Offline AI Copilot:
- Ollama (Local LLM server, quantized Qwen-3 8B)
- ChromaDB (Local vector database for RAG)
- SentenceTransformers (Local embeddings)

Visualization & Graph:
- NetworkX (graph topology BFS & alert correlation)
- Streamlit & Plotly (interactive NOC dashboard)

Languages: Python 3.14
Cost: $0 recurring licensing (100% open-source)
