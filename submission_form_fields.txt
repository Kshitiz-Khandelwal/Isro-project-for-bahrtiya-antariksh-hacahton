FIELD 1: Brief about your Idea (Max 1024 characters)
================================================================================
An Air-Gapped Predictive NOC Copilot for Secure MPLS/SD-WAN Operations (Problem Statement 13).

Our platform shifts network operations from reactive alerting to predictive intelligence — entirely offline. It forecasts SLA breaches 15-30 minutes before they occur using Prophet time-series models, classifies fault types (congestion, BGP instability, tunnel degradation, policy drift) via XGBoost with 94% accuracy, and explains each prediction using SHAP-attributed telemetry signals.

A locally-hosted Qwen-3 8B LLM (served via Ollama) generates structured JSON remediation checklists grounded in retrieved runbook context from ChromaDB. NetworkX graph traversal maps downstream topology impact for every alert.

The entire system — ML inference, LLM reasoning, vector search, and dashboard — runs on a single air-gapped workstation with zero cloud API calls, zero outbound traffic, and zero software licensing costs. A live compliance verification script proves air-gap integrity during operation.

This is not just a monitoring tool. It is a complete autonomous NOC assistant that predicts, explains, correlates, and remediates — fully offline.

FIELD 2: What problem are you trying to solve? (Max 2000 characters)
================================================================================
Modern MPLS/SD-WAN networks serving mission-critical infrastructure face four fundamental challenges:

1. REACTIVE MONITORING: Current NOC tools alert operators only after failures have already caused service degradation. By the time an alert fires at 90% utilization, packet loss and SLA violations are already occurring. Operators need predictive lead time — knowing that a link WILL saturate in 14 minutes gives them time to act before impact.

2. ALERT FATIGUE WITHOUT CONTEXT: A single upstream failure cascades into dozens of downstream alerts. Operators manually correlate hundreds of syslog entries, SNMP traps, and NetFlow records to identify root cause. They need automated topology-aware correlation that collapses cascading alerts into a single incident with identified scope.

3. KNOWLEDGE SILOS: Critical operational knowledge lives in 40-page static runbooks stored on shared drives. During incidents, operators waste precious minutes searching for the right procedure. They need automated retrieval of the exact relevant runbook section, injected directly into the diagnostic context.

4. SECURITY CONSTRAINTS IN CLASSIFIED ENVIRONMENTS: Government, defense, and space organizations like ISRO operate under strict air-gap requirements. They CANNOT use cloud-hosted AI services (ChatGPT, Claude, Copilot) because classified network telemetry must never leave the secure boundary. Yet these organizations need the same AI-powered operational intelligence that commercial enterprises enjoy.

Our solution addresses all four gaps simultaneously:
- Prophet forecasting estimates exact minutes-to-SLA-breach
- XGBoost + IsolationForest classify fault type with 94% accuracy and flag anomalies
- SHAP explainability attributes which specific telemetry signals drove each prediction
- NetworkX BFS traversal identifies every downstream device and VRF service affected
- ChromaDB RAG retrieves matching runbook sections automatically
- A locally-quantized Qwen-3 8B LLM synthesizes all context into a structured remediation checklist with confidence scoring

Everything runs on one machine. Zero cloud. Zero data leakage. Zero recurring cost.

FIELD 3: Technology Stack being used (Max 1024 characters)
================================================================================
Infrastructure & Simulation:
- Containerlab + FRRouting (BGP/OSPF/MPLS/VRF network simulation)
- tc netem (fault injection), iperf3 (traffic generation)
- FastAPI (Mock SD-WAN Controller REST API)

Telemetry Collection:
- Telegraf (SNMP MIB polling, syslog ingestion, HTTP scraping)
- softflowd + nfdump (NetFlow/IPFIX export and analysis)

Predictive ML Engine:
- XGBoost (multiclass fault classification, 94% accuracy)
- Prophet (time-series SLA breach forecasting)
- IsolationForest (unsupervised anomaly detection)
- SHAP (explainable AI feature attribution)

Offline AI Copilot:
- Ollama (local LLM server, Qwen-3 8B Q4_K_M quantized)
- ChromaDB (persistent local vector database for runbook RAG)
- SentenceTransformers all-MiniLM-L6-v2 (local embeddings)

Graph Analytics:
- NetworkX (topology BFS traversal, alert correlation)

Dashboard:
- Streamlit + Plotly (interactive NOC web console)

Languages: Python 3.14
Cost: $0 licensing (100% open-source)
